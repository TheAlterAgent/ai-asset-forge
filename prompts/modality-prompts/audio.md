# 音频/音乐生成 Prompt 模板

## 角色配音
```
[gender] voice, [age_range], [emotion],
speaking line: "[dialogue_text]"
[pace_description], [tone_description],
clear pronunciation, game voiceover quality,
2 seconds, mono, 44100Hz
```

## 背景音乐
```
[genre] music, [mood_description],
[instrument_1] and [instrument_2] leading,
[tempo_description], [dynamic_arc],
[cultural_style] influence,
seamless loop, game soundtrack quality,
2 minutes, stereo, 48000Hz
```

## 音效
```
[sound_type] sound effect,
[source_description], [intensity_level],
[processing_description] (reverb/distance/pitch),
crisp and punchy, game SFX quality,
1 second, mono, 44100Hz
```

## 环境音
```
Ambient [location_type] atmosphere,
[distant_sounds], [subtle_movements],
[nature/urban/indoor] elements,
low volume, immersive background,
seamless loop, game ambience quality,
1 minute, stereo, 48000Hz
```
